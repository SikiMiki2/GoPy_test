# GoPy Test

A playground for exploring [gopy](https://github.com/go-python/gopy), the tool that generates Python bindings for Go packages. This project also holds the demos for my talk.

## Project Layout

### `_examples/`

Examples taken from the official gopy repository.

- Used for reading and getting familiar with gopy
- **Not** part of the talk

### `my_demos/`

My own examples, written for the talk.

- The **initial example** comes first and introduces the basics
- The remaining demos build on it, in presentation order

### Everything else

Scratch files and experiments, used for testing purposes only. None of it goes into the talk.
